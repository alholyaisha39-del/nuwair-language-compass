نشر مبادرة نوير على GitHub Pages
================================

هذه نسخة موقع ثابتة (HTML/CSS/JavaScript) وتتصل بمشروع Firebase الحالي نفسه: bosel-8eabf. لا يوجد خادم Node أو خطوة Build.

قبل الرفع
---------
1) أنشئي مستودع GitHub جديدًا باسم بسيط مثل nuwair-language-compass. يفضّل أن يكون Public إذا كنتِ تستخدمين GitHub Free مع GitHub Pages.
2) ارفعي محتويات هذا المجلد إلى جذر المستودع مباشرة، بحيث يظهر index.html في أول مستوى، وليس داخل مجلد إضافي.
3) من Settings > Pages اختاري Deploy from a branch، ثم branch: main والمجلد: /(root)، ثم Save.
4) بعد النشر سيظهر رابط شبيه بـ https://USERNAME.github.io/REPOSITORY/، ولوحة المعلمة في نهايته /teacher/ .

إعداد Firebase الضروري
----------------------
5) افتحي Firebase Console للمشروع bosel-8eabf. من Authentication > Settings > Authorized domains أضيفي النطاق USERNAME.github.io فقط (من دون https أو اسم المستودع أو الشرطة المائلة).
6) من Firestore > Rules انشري ملف firestore-rules-ALL-SITES.txt كاملًا الموجود في هذه الحزمة. هذا الملف يحافظ على قواعد ريم ومنى ويضيف صلاحيات بنك أسئلة نوير. لا تستبدليه بقواعد مختصرة من الإنترنت.
7) لا تغيّري firebase.js ولا Project ID ولا أسماء مجموعات البيانات. ولا تحذفي موقع Netlify القديم قبل التأكد من عمل الرابط الجديد.

إدارة المسودات
-------------
- بعد تسجيل دخول المعلمة تظهر إدارة مسودات الأسئلة للأسبوع 1 إلى 10.
- الأسابيع 1–3 تحتوي الأسئلة التي سبق اعتمادها.
- الأسابيع 4–10 تُنشأ كمسودات فارغة؛ يلزم إدخال الأسئلة فيها قبل اعتمادها. لم نضع أسئلة غير مراجعة من عندنا.
- يمكن تعديل نص السؤال والخيارات والإجابة الصحيحة، حذف سؤال أو إضافة بديل، وتعديل النص القرائي.
- حفظ المسودة لا يغيّر النسخة التي تراها الطالبات. زر «اعتماد الأسبوع كاملًا» ينشر النسخة المعدلة في بنك الأسئلة، وبعده فقط يمكن تفعيل الأسبوع يدويًا.
- يلزم وجود 10 أسئلة صالحة في كل قسم ونص قرائي قبل اعتماد الأسبوع.

حماية النتائج أثناء النقل
-------------------------
- نتائج الطالبات محفوظة في Firestore ضمن مشروع Firebase، وليست داخل Netlify أو GitHub. إبقاء المشروع والمجموعات والقواعد نفسها يحافظ على النتائج الموجودة.
- لا تحذفي مستندات nuwair12_results أو nuwair12_enrollments ولا تعيدي إنشاء مشروع Firebase.
- تغيير النطاق من Netlify إلى GitHub قد يجعل Firebase Anonymous Auth ينشئ UID جديدًا في المتصفح؛ لذلك النتائج القديمة تبقى موجودة في لوحة المعلمة، لكن قد لا تستعيد الطالبة جلستها/تقدمها القديم تلقائيًا من النطاق الجديد.
- احتفظي برابط Netlify القديم حتى تختبري دخول المعلمة والطالبات وقراءة النتائج من GitHub.

تنبيه خصوصية
-------------
مستودع GitHub العام يجعل ملفات الموقع وكود الواجهة متاحة للقراءة العامة. لا تضعي كلمات مرور المعلمة أو أي بيانات شخصية للطالبات داخل ملفات الموقع أو المستودع. إعدادات Firebase الموجودة في الواجهة مخصصة للتطبيق، والحماية الفعلية تكون بقواعد Firestore وAuthentication.
