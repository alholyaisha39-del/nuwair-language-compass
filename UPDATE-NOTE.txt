نسخة GitHub Pages + إدارة مسودات الأسئلة

- إضافة محرر أسئلة للأسابيع 1–10 في لوحة المعلمة.
- يمكن تعديل السؤال والخيارات والإجابة، حذف السؤال وإضافة سؤال بديل، وتعديل نص القراءة.
- حفظ المسودة لا يغيّر النسخة المنشورة للطالبات.
- اعتماد الأسبوع كاملًا ينشر النسخة الجديدة؛ والتفعيل اليدوي يبقى خطوة منفصلة.
- الأسابيع 1–3 تم تهيئتها من ملفات الأسئلة التي سبق اعتمادها. الأسابيع 4–10 مسودات فارغة تنتظر كتابة الأسئلة ومراجعتها.
- الطالبات يقرأن النسخ المعتمدة فقط من Firestore.
- تمت إضافة قواعد Firestore لبنك أسئلة نوير دون حذف قواعد المواقع الأخرى.
- إضافة .nojekyll وتعليمات نشر GitHub Pages.
- نتائج الطالبات تبقى في Firebase bosel-8eabf؛ لا تحذفي موقع Netlify حتى تختبري GitHub.
